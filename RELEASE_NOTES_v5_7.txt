Signal Lab v5.7 — Windows 자동 모의매매 진입·CLOSE 알림

1. 실제 가상 체결에 성공한 경우에만 Windows 진입 알림
2. 손절 또는 3차 익절 등 최종 CLOSE에만 수익/손실 포함 알림
3. 부분 익절은 거래 기록으로만 표시, 중복 시스템 알림 방지
4. 모바일과 PC 공통 알림 설정 및 최근 100개 이벤트 이력
5. 별도 브라우저 없이 서버에서 PowerShell Windows 트레이 알림 실행
6. 테스트 버튼: 진입 테스트 / CLOSE 테스트 (모의 포지션 생성 없음)
7. 기존 %LOCALAPPDATA%\SignalLab PNL 및 거래기록 유지

중요: 알림 수신을 위해 Windows PC에 로그인한 상태로 서버를 켜 두어야 합니다.
환경에 따라 알림이 차단될 수 있으니 Windows 알림 설정과 방해 금지 모드를 확인하세요.
