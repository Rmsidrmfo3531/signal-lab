Signal Lab v5.5 - Windows 실행 방법

1. ZIP 파일 우클릭 -> [모두 압축 풀기]
2. 압축 푼 폴더에서 start.bat 실행 (확장자가 숨겨져 있으면 이름이 start로 표시됨)
3. 휴대폰에서도 볼 때는 PC에서 start_mobile.bat 실행
4. PC 접속: http://127.0.0.1:3000
5. PC와 휴대폰이 같은 Wi-Fi인 경우 모바일 실행창의 IP 주소로 접속
6. 실행 중인 명령 프롬프트(검은 창)는 닫지 마세요.
7. Node.js 22 이상 설치 필요: https://nodejs.org/

참고: start.bat만 따로 옮기면 서버 실행이 되지 않습니다. 압축파일 전체를 같은 폴더에 추출하세요.
