Signal Lab v5.0 — 크립토 + TradFi 통합판 (PC / 모바일)

[빠른 시작]
1. 모든 ZIP 파일 압축 해제 후 Windows에서 start.bat 실행 → PC: http://127.0.0.1:3000
2. PC와 휴대폰이 같은 개인 Wi-Fi에 있다면 start_mobile.bat 실행 후 명령창의 LAN 접속 주소를 휴대폰에 입력하세요.
   초기 접속 암호는 검은 명령창에 표시됩니다. 라우터 포트 포워딩은 하지 마세요.
3. 메인 시그널 목록 바로 아래 'TradFi 시장 · 확정 기술 패턴' 영역 확인.
4. 공식 Variational API에서 TradFi 상품이 조회되면 Variational Mark / Bid·Ask / 롱·숏 펀딩 / TradingView 참조 차트가 표시됩니다.

[TradFi 패턴 스캔(선택 기능)]
Variational 공개 API는 1시간·4시간 전체 캔들 데이터를 제공하지 않습니다.
따라서 외부 Twelve Data API 키 없이 TradFi 차트 패턴을 임의로 만들어 내지 않습니다.
Twelve Data 계정과 데이터 제공 권한이 있다면:
1. .env.example 복사해서 .env 만들기
2. TWELVE_DATA_API_KEY=본인_키 기입
3. 기본 스캔 대상 XAU/XAG. TRADFI_FEED_SYMBOLS=XAU,XAG 에서 변경 가능
4. 기본 TRADFI_SCAN_INTERVAL_MS=900000 (15분마다) / 5분 이상으로 변경 가능.
   REST 간격 스캔은 틱 단위 완전 실시간이 아닙니다. 서비스 가입 플랜에 따라 지연/요금/호출 제한이 있습니다.
5. 서버 재시작 후 TradFi 영역의 외부 OHLC 검사 상태를 확인하세요.

[안전]
- 확인된 SWAP / 일부 TradFi PERP만 표시, API 실패 시 미검증 시장/신호 제외
- Variational 참고 호가 != 실제 RFQ 체결가격; 주문 전에 해당 플랫폼에서 확인
- 지역별 이용 제한이 있을 수 있으며 거래 주문을 자동으로 넣지 않습니다.
- Telegram을 설정하면 새로운 확정 TradFi 패턴의 링크 알림도 제공(데이터 공급자가 정상일 때만).
- 기존 크립토 Signal Lab 실시간 WebSocket 스캐너는 별도로 유지됩니다.
- 외부 데이터를 가져올 수 없는 상황에서 신호가 0개여도 화면 자체는 작동합니다.
