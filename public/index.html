실계좌 카피 매매

실계좌 상태를 불러오는 중입니다.

설명

실제 돈이 들어가는 BingX 실계좌입니다. 텔레그램 채널 카피 매매만 여기서 돌아가며, 신호 전략(테스트넷)과 원장·잔고·활성화 스위치가 모두 따로입니다. 서버를 다시 켜면 항상 비활성으로 시작합니다. 거래소 포지션은 조회만 하며(주문 없음) 같은 종목·방향의 카피 기록이 있으면 카피, 아니면 수동으로 표시합니다.

설명 · 안전 장치

기본 OFF. .env의 LIVE_TRADING_MODE(OFF·TESTNET·LIVE)와 거래소 API 키가 있어야 하고, 서버를 켤 때마다 여기서 다시 활성화해야 주문이 나갑니다. TESTNET은 거래소의 모의 자금 계정이고, LIVE는 실제 돈이며 LIVE_TRADING_CONFIRM도 필요합니다. API 키는 이 화면에 입력하지 마세요.

최종 신호가 나오면 손절이 붙은 진입 주문, 목표 3개(40/35/25%), 매물대 분할 추매 주문을 거래소에 넣습니다. 긴급 정지는 새 진입만 막고 보유 포지션의 손절 주문은 남겨 둡니다. 미실현 손익은 거래소가 계산한 값을, 없으면 평균 진입가·현재가로 추정해 “추정”으로 표시합니다. 종료 손익은 거래소 정산 기록(실현 손익·수수료·펀딩)을 쓰고, 읽지 못하면 “추정”으로 표시합니다.

자동 모의매매는 꺼져 있습니다(PAPER_TRADING=on으로 다시 켤 수 있음). 예전 모의 기록은 지우지 않고 보관합니다.

번역은 자동번역(정확성 미검증)이며 실패하면 원문을 보여 줍니다. 호재·악재는 키워드 분류로, 원인·영향을 확정하지 않습니다.
