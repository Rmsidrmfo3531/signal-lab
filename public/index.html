암호화폐 분석은 Binance TRADING 상태의 USDT 무기한 선물을 우선 사용하고, 바이낸스에 없는 코인(시총 기준 통과)은 Gate.io·BingX 차트로 같은 규칙을 적용합니다. 완전히 마감된 1H·4H와 EMA200용 충분한 4H 데이터를 확인합니다. 종합점수는 4H EMA200 15점 · EMA100 5점 · 1H EMA20 10점 · 가격 패턴·확정 강도 25점 · ADX/DMI 15점 · RSI 10점 · MACD 5점 · 패턴별 거래량 10점 · ATR 5점의 단일 100점이며 승률이 아닙니다.

메인에는 기술·신선도·호가·위험·매물대 목표·현재 진입 조건을 통과한 최종 신호만 표시합니다. 점수 계산 불가는 ‘평가 불가’로 표시합니다. Telegram은 이 최종 신호 목록과 동일한 검증 결과만 발송합니다. 80점 관찰·뉴스 Telegram 알림은 중지했습니다.

TP1 40% · TP2 35% · TP3 25%는 실제 체결량 기반 매물대의 유효한 3개 목표가가 확인된 신규 거래에 적용합니다. TP_PROFILE_UNAVAILABLE이면 진입 보류하며 고정 2R·3R·4R 자동 대체는 OFF입니다. 실제 주문은 OFF입니다.

WebSocket 가격·봉 마감 이벤트와 REST 순환 보완을 사용합니다. 전체 종목을 매초 분석하지 않습니다. 아래에 실제 순환 검사 범위·주기·직전 성공/실패를 표시합니다.

설명 · 안전 장치

기본 OFF. .env의 LIVE_TRADING_MODE(OFF·TESTNET·LIVE)와 거래소 API 키가 있어야 하고, 서버를 켤 때마다 여기서 다시 활성화해야 주문이 나갑니다. TESTNET은 거래소의 모의 자금 계정이고, LIVE는 실제 돈이며 LIVE_TRADING_CONFIRM도 필요합니다. API 키는 이 화면에 입력하지 마세요.

최종 신호가 나오면 손절이 붙은 진입 주문, 목표 3개(40/35/25%), 매물대 분할 추매 주문을 거래소에 넣습니다. 긴급 정지는 새 진입만 막고 보유 포지션의 손절 주문은 남겨 둡니다. 미실현 손익은 거래소가 계산한 값을, 없으면 평균 진입가·현재가로 추정해 “추정”으로 표시합니다. 종료 손익은 거래소 정산 기록(실현 손익·수수료·펀딩)을 쓰고, 읽지 못하면 “추정”으로 표시합니다.

자동 모의매매는 꺼져 있습니다(PAPER_TRADING=on으로 다시 켤 수 있음). 예전 모의 기록은 지우지 않고 보관합니다.
