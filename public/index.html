검색 대기

암호화폐 분석은 Binance TRADING 상태의 USDT 무기한 선물만 사용합니다. 완전히 마감된 1H·4H와 EMA200용 충분한 4H 데이터를 확인합니다. 종합점수는 4H EMA200 15점 · EMA100 5점 · 1H EMA20 10점 · 가격 패턴·확정 강도 25점 · ADX/DMI 15점 · RSI 10점 · MACD 5점 · 패턴별 거래량 10점 · ATR 5점의 단일 100점이며 승률이 아닙니다.

메인에는 기술·신선도·호가·위험·매물대 목표·현재 진입 조건을 통과한 최종 신호만 표시합니다. 점수 계산 불가는 ‘평가 불가’로 표시합니다. 80점 이상 알트코인 관찰 알림은 Telegram 전용이며 이 화면과 자동주문에 사용하지 않습니다.

최종 신호 점수 기준: 서버 설정 조회 중 · 실전 성능 미검증 (UNVERIFIED) · 실거래 승인 아님

WebSocket 가격·봉 마감 이벤트와 REST 순환 보완을 사용합니다. 전체 종목을 매초 분석하지 않습니다. 아래에 실제 순환 검사 범위·주기·직전 성공/실패를 표시합니다.
