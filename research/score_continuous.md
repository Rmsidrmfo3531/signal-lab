## 바뀐 규칙

`scoreScalpSetup`(scalp_reversal.mjs)의 6개 항목은 예전 5점 단계의 경계를 잇는 직선 보간 후 정수 반올림입니다(`SCALP_SCORE_CURVES`). 항목 최대, 합계 100, 65점 기준, 등급, 크기 배수는 그대로입니다.

| 항목 (최대) | 기준점 (값 → 점수) |
|---|---|
| 급변 % (25) | 2.0 → 0, 2.5 → 5, 3.5 → 15, 5.0 이상 → 25 |
| ATR 배수 (15) | 2 → 0, 3~4.5 → 15, 6 → 10, 9 이상 → 5 (0점 절벽 없음) |
| 되돌림 % (10) | 0 → 0, 15~30 → 10, 45 이상 → 0. 반전 꼬리 또는 직전 봉 돌파 마감이면 최소 5 |
| 거래량 배수 (5) | 2 → 0, 5 이상 → 5 |
| 순 손익비 (5) | 0.8 → 0, 1.4 이상 → 5 |
| RSI (5) | 롱 30 → 0, 18 이하 → 5 / 숏 70 → 0, 82 이상 → 5 |
| 4H 추세 (20) · BTC 추세 (15) | 그대로 3단계 (같은 방향 20/15, 횡보 10, 반대 0) |

추세 두 항목은 `fourHourTrend`가 EMA100·200으로 'up'/'down'/'range'만 돌려주고 세기 값을 내보내지 않으며, 과거 기록에도 세기 값이 없습니다. 그래서 3단계를 유지했습니다.

부수 수정: 값이 없을 때(null)는 0점입니다. 예전에는 롱의 `rsiPeak`가 없으면 `Number(null)=0`으로 읽혀 RSI 5점을 받았습니다.
