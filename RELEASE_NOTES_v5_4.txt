SIGNAL LAB v5.4 — 분석은 되지만 스캔 결과가 0개로 보이는 문제 수정

원인
- 서버의 누적 분석 횟수는 종목별 고유 건수가 아닌 반복 조회 수임.
- v5.3의 확정 패턴 목록은 기술 점수, 15분봉, Variational 호가를 모두 통과한 것만 보여 차트 패턴 후보도 숨겨졌음.
- Variational 공식 API가 초기 연결에 실패하면 Binance에서는 기술 분석이 진행되지만 화면에는 연구용 종목 목록이 보이지 않았음.

수정
- 1시간봉 구조 패턴을 발견한 종목은 기술 조건 미달/15분 미확인/호가 보류 여부와 함께 표에 표시. 주문 권고 아님.
- 진입 검증 통과 신호 및 텔레그램 알림, 자동 모의매매는 모든 기존 필수 조건을 통과할 때만 허용.
- Binance-only 관찰 종목은 Variational 검증 복구 전까지 별도 라벨로 표시, 주문 바로가기 비활성.
- 최근 실제 검사한 24개 종목의 상태를 표시 (패턴이 없더라도 확인 가능).
- 분석 단계별 숫자와 주요 탈락 이유 5개 표시. JSON: /api/scan/diagnostics
- 누적 스캔 횟수와 실제 고유 종목 수 구분. PC/모바일 동일 UI.
- 데이터 저장은 기존 %LOCALAPPDATA%\SignalLab 폴더를 그대로 사용. 거래 기록 보호.

업데이트
1. 기존 server 창 모두 종료.
2. 새 ZIP 전체 압축 해제.
3. start.bat 또는 start_mobile.bat 실행.
4. 브라우저 Ctrl+F5 새로고침.
5. 스캔 상단 진단 / 최근 검사 목록 확인.

알림 기준을 낮춘 것이 아닙니다. 후보 관찰은 실제 주문 검증 통과와 다릅니다.
실제 Windows에서의 거래소 접속·모바일 화면은 설치 환경에서 확인해야 합니다.
